Jarvis — a personal AI assistant

Builder · 2026 – present

Jarvis is the personal AI assistant Ferran Teixidor built in 2026 to run university, weekend work and several projects at once. It is built on Claude Code, Anthropic's coding agent, and connected to the tools he already used.

What it does

  • Morning briefing at 7:00 on Telegram, sent by a GitHub Actions job: news by sector plus a draft LinkedIn post.
  • Task management in ClickUp: prioritising, archiving and a daily reminder for university work.
  • Research loops: a command that researches open questions, checks official sources and writes the findings to notes.
  • Long-term memory in plain Markdown files and an Obsidian vault, so every session starts with context.
